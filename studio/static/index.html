🤖 标准化自动化 AI 接口说明

打开交互式 Swagger 文档 ↗

外部 AI Agent、Python 脚本、n8n、Coze 或定时任务可直接调用以下本机 REST API 实现全自动“文案/音频 → 数字人视频 → 成片下载”。

GET /api/v1/health — 全系统健康检查（Docker/TTS/队列/GPU/告警）
GET /api/v1/models — 获取可用数字人模特列表及底模健康状态
POST /api/v1/tts/synthesize — 单独调用 IndexTTS2 合成音频（全参数）
POST /api/v1/jobs — 单条创建数字人视频（支持文案+TTS参数 或 本地音频直驱）
POST /api/v1/jobs/batch — 批量导入生成数字人视频
GET /api/v1/jobs/{id} — 查询实时阶段、帧进度%、ETA、报错与源文件路径
POST /api/v1/jobs/{id}/cancel — 实时中断运行中/排队中任务
POST /api/v1/jobs/{id}/retry — 失败/中断任务一键重试
GET /api/v1/jobs/{id}/download — 直接下载最终成片 MP4
POST /api/v1/system/recover — 一键自愈拉起异常容器与守护服务
Python 自动化调用示例（已自动填入你的真实模特 ID）
