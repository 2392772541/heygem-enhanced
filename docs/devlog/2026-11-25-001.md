# 开发档案：本机数字人自动同步支持固定域名密码锁

- **项目标识**：HeyGem-Enhanced
- **归档时间**：2026-11-25 14:49:58
- **关联提交**：eaf3d12ddef57117ca4e15afd3992eb1e22766ef

## 一、需求背景与目标
修复本机8390云端自动同步未自动拉回新视频的问题

## 二、现象排查与根因分析
本机8390仍绑定昨日trycloudflare临时链接，且cloud_auto_sync未支持gz.grzdt.com固定网关BasicAuth与前缀路径拼接

## 三、方案设计与技术决策
为cloud_auto_sync增加固定网关BasicAuth自动读取、防重复路径拼接与503休眠提示，并将cloud_url永久切到https://gz.grzdt.com/heygem，用WMI常驻拉起8390

## 四、核心实现与变更范围
- `adapter/config.json`
- `adapter/heygem_index_tts2_adapter.py`
- `core/cloud_auto_sync.py`
- `studio/server.py`
- `studio/static/app.js`
- `studio/static/index.html`
- `adapter/tests/`

## 五、测试验证与客观证据

```text

```
